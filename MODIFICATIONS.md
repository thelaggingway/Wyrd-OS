# Modifications

Wyrd-OS is a modified version of agentes.chat (https://github.com/agentes-chat/agentes-chat), licensed under
the GNU AGPL-3.0-only with the terms in [NOTICE](NOTICE). This file lists what WyrdWerk changed and when, as
section 5(a) of the license asks. Upstream's own history is in the Git log before the first entry below.

| Date | Based on upstream | Change |
| --- | --- | --- |
| 2026-11-19 | v0.1.8 (`6576de568`) | Added `brand/`: at image build, `brand/apply.ts` replaces the product name in the English strings (`packages/i18n/src/en.ts`), the page title and share card (`apps/web/index.html`), the logo (`packages/ui/src/components/Logo.tsx`), the name shown in authenticator apps (`apps/server/src/auth.ts`), and the icons and email pictures in `apps/web/public`. The license attribution and upstream's names for its own hosted service are left as they are. |
| 2026-11-19 | v0.1.8 | English only: `brand/apply.ts` sets every other language to `ready: false` in `packages/i18n/src/locale.ts`. The translations stay in the source. |
| 2026-11-19 | v0.1.8 | The About screen's copyright line says this is a modified version, by whom and since when; the source link there comes from `SOURCE_URL`. |
| 2026-11-19 | v0.1.8 | `Dockerfile` runs `brand/apply.ts` before the build. Added `.github/workflows/wyrd-image.yml` to build and publish the image. Notices added to `README.md` and `NOTICE`. |
| 2026-11-19 | v0.1.8 | Quiet idle tabs: `apps/web/src/lib/dormant.ts`, wired in `apps/web/src/realtime/context.tsx` and `apps/web/src/main.tsx`. After 5 minutes with no input and no agent working, a tab closes its live connection and stops polling, so the server's machine can pause; the first input reconnects it and refetches what is on screen. |
| 2026-11-19 | v0.1.8 | The agents' computer on the server reaches the app on its own loopback port: `docker-compose.yml` publishes `127.0.0.1:${HOST_COMPUTER_PORT:-3901}`, and the setup (`appOnThisMachine` in `packages/setup/src/lib.ts`) points the runner there instead of `HOST_PORT`. Documented in `SELF_HOSTING.md`. |
| 2026-11-19 | v0.1.8 | Operator `GET /activity` (`apps/server/src/operator/activity.ts`, `packages/engine/src/server-activity.ts`): whether the machine this server runs on may sleep. `busy` with its reasons (runs, a run waiting for a computer, computer tasks, a person on an agent's screen, a computer asked for in the last 2 minutes, background jobs processing or due), `lastUsedAt`, `nextDueAt` (the next routine or queued job) and `mailWatches`. Documented in `SELF_HOSTING.md`. |
| 2026-11-19 | v0.1.8 | `.github/workflows/ci.yml`: the `build` job (and so `publish`), which pushes upstream's images to `ghcr.io/agentes-chat`, runs only in `agentes-chat/agentes-chat`. This fork's image comes from `wyrd-image.yml`. |
| 2026-11-20 | v0.1.8 | Added `deploy/orble/`: a watchdog that suspends an idle Orble box through Orble's in-box API when `GET /activity` says nothing is going on, and a firewall service that lets only the watchdog's container reach that API. |
| 2026-11-23 | v0.1.8 | Agents' `search_context` takes `after`, `before` and `sort` (the index's ADR 0123 filters), and without `query` lists a window newest first (`searchWindow` in `packages/engine/src/context/tools.ts`). `search_wiki` and `read_wiki_page` show each page's dates (`packages/engine/src/wiki-tools.ts`). |
| 2026-11-23 | v0.1.8 | The Librarian (`packages/engine/src/librarian.ts`): every business team template also makes it (`team-templates.ts`). A nightly routine records the day's decisions, facts, how-tos, open questions and files in the wiki with their sources and dates, keeps a dated Index in every agent's context, and supersedes decisions instead of erasing them; a weekly routine tidies. It reads every public channel without joining them (`agents.setup.reads`, read by `agentSearchChannels`), never private ones or DMs, and has only read tools plus the wiki and Drive (`createAgent`'s `scopes`, which only narrows the defaults). `NO_GUESSING` is the source-only rule every Wyrd-OS template agent's instructions end with. |
| 2026-11-23 | v0.1.8 | The "Indian SME" team template (`packages/engine/src/india-team.ts`, id `india` in `team-templates.ts`): Sales and Marketing, Digital Marketing, Research, Legal (general guidance for SMEs) and Finance and Accounting, each in its own channel with one read-and-report routine (IST), plus the Librarian. Their instructions state no rate, due date or section from memory (each is looked up and cited), require a person's approval for every outward action, and end with `NO_GUESSING`. English only; no skills or hello lines yet. |
| 2026-11-23 | v0.1.8 | The right hand is the Chief of Staff (`RIGHT_HAND_DEFAULTS` in `right-hand.ts`, `RIGHT_HAND_DEFAULT` in `packages/client/src/lib/right-hand.ts`): name "Chief of Staff", handle `chief` for new workspaces (existing ones keep theirs). Its prompt (`right-hand-prompt.ts`) calls it a general-purpose assistant that directs and supervises no other agent and decides no approval, and ends with `NO_GUESSING`. The "lodestar" line shows only for a right hand still called Lodi. |
| 2026-11-23 | v0.1.8 | Fixes from a 5-day Librarian simulation. An agent set to read every public channel no longer reads the conversation its routine reports to (the owner's DM; `agentSearchChannels` in `search.ts`). `update_wiki_page` refuses a `replace_section` whose heading isn't on the page instead of appending a new section, and the wiki tools drop `read_wiki_page`'s own header and "Linked from" line from saved text (`withoutReadFrame` in `wiki-tools.ts`; `findSection` exported from `wiki.ts`). `NO_GUESSING` forbids joining two sources into a cause; the Librarian's prompts send hearsay to Open questions, require a search before saying something is absent, page through busy days, mark older quote versions, keep placeholders out of the Index, and report only checks it made. |
| 2026-11-23 | v0.1.8 | Fixes from the Librarian simulation's rerun. A routine of an agent set to read every public channel no longer quotes what was said where it reports (the owner's DM) in its "# Where your report goes" block (`routineContext` in `context.ts`). The wiki tools drop a first line that is the page's own title as a heading (`withoutReadFrame` in `wiki-tools.ts`). The Librarian's rules list hearsay trigger phrases, require a search for each with its query and result count in the Log, have a search's result count copied rather than retold, and allow a "Related:" link only when one source names both pages (`librarian.ts`). |
| 2026-11-25 | v0.1.8 | The image is built in two stages (`Dockerfile`): the final one keeps only the server's production dependencies (`bun install --production --filter @agenteschat/server`) after the web app and the runner are built; the phone and desktop apps are taken out of the workspace and the lockfile first, so neither the build tools, React Native, Expo nor Bun's download cache reach it. |
| 2026-11-25 | v0.1.8 | `.github/workflows/demo-wake.yml` wakes the demo server (an InstaBox machine that pauses itself when idle) 10 minutes before its routines are due and keeps it awake for 40 minutes; its URL is the secret `WYRD_DEMO_URL`. |
